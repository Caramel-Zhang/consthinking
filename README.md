# Consthinking

这是一个「反思总结 + 兴趣资讯」安卓应用的 MVP 仓库，包含：

- `android-app/`：Android 客户端骨架（悬浮窗、录音触发、双击截图触发、定时任务配置入口）。
- `backend/`：FastAPI 服务骨架（接收录音/截图、保存当日上下文、定时推送日报/周报/月报、新闻简报与播客任务占位）。

> 当前版本已按你的需求把流程和结构搭好，AI API（如 GLM）保留接口，尚未填入真实 Key 与推理实现。

## 功能映射

### 1) 反思总结悬浮窗

- 常驻右下角半透明悬浮窗（贴右侧）。
- 向左拉动可展开本体。
- 单击：开始/结束录音并上传服务器。
- 双击：截图并上传服务器，不保存到相册。
- 服务端收到后返回 `已保存`，并保留当天上下文。
- 每天固定时间推送日报；每周日推送周报；每月最后一天推送月报。

### 2) 兴趣新闻与电子报 / 播客

- 用户可设置最多 3 个感兴趣领域。
- 服务端按固定时间抓取与总结，生成电子报和「最新简讯」播客（当前为任务占位）。

### 3) 目录导航

- 每天早 7 晚 7 自动更新目录导航：
  - 兴趣资讯链接
  - 热门榜单短视频链接
  - 热门小程序/小游戏链接
  - 白嫖/优惠券/羊毛链接

## 运行方式（后端）

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn server:app --reload --port 8080
```

## Android 说明

`android-app/` 是 Android Studio 可导入的 Kotlin 项目骨架，重点实现了：

- 悬浮窗 Service 结构
- 单击/双击手势分发
- 录音上传流程
- 截图上传流程入口（MediaProjection 需要用户授权，已预留）
- 用户配置数据模型与 API 占位

你可以直接在 Android Studio 打开后补齐签名、依赖版本与真机权限联调。
